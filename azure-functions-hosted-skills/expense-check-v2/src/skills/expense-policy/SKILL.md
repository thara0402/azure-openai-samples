# 経費申請前の確認

このサンプル規定は申請前の確認用であり、承認や却下を行うものではありません。
以下にない規定や判断を作らず、入力された全明細を順に確認してください。

1. 明細番号 `expense_number` は入力配列の順に1から付けます。
2. すべての明細の `receipt_attached` を確認し、`false` なら領収書未添付を理由に含め、要確認とします。
3. `meal` の上限は1件あたり3,000円です。`amount` が上限を超える場合は要確認とし、超過額を正確に理由に示します。
4. `transportation`、`lodging`、`supplies`、`other` にはこのサンプルで上限規定がありません。規定に適合していると推測せず、上限が定められていないことを理由に含め、要確認とします。
5. 各明細には当てはまる理由をすべて含めます。食事代の上限超過と領収書未添付が両方当てはまる場合は、両方を示します。
6. 食事代が3,000円以下で領収書が添付されている明細は `no_issues_found` とし、`reasons` を空にします。それ以外は `needs_review` とします。
7. 要確認の明細が1件でもあれば全体を `needs_review`、それ以外は `no_issues_found` とします。
